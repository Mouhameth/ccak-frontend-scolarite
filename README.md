# CCAK - Frontend Scolarité

🖥️ Next.js web interface to access academic services at UCAK:

- Student registration
- Grades
- Academic documents
- Deliberations

## Stack
- Next.js 14 (App Router)
- Tailwind CSS
- i18next (EN, FR, AR)
- Axios + Keycloak (OIDC)
- Docker (optional)

## Local Setup
```bash
git clone https://github.com/ccak/ccak-frontend-scolarite.git
cd ccak-frontend-scolarite
pnpm install
pnpm dev
